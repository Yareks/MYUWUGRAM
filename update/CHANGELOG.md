# UwUgram

Файл списка изменений. Его правят прямо в репозитории: `update/CHANGELOG.md`.
Клиент забирает этот текст и, если сети нет, показывает последнюю полученную копию.

## Сейчас

- В строке настроек UwUgram и в шапке вкладки стоит выбранная иконка приложения.
- Канал по умолчанию: beli_meow. Имя можно сменить в `update/channel.md`.
- Новая сборка предлагается при запуске. Если плашку закрыть, пункт «Обновить» остаётся сверху в настройках UwUgram.
