# MeowGram иконка приложения

Иконка приложения меняется **в момент сборки** (а не в рантайме) скриптом
`scripts/generate_meowgram_icon.sh` — это единственный способ поставить
произвольную картинку на место настоящей иконки лаунчера на Android.

## Как поставить свою иконку

1. Положи свою картинку в этот файл: `branding/icon.png`
   (квадратная, желательно от 512×512; подойдёт jpg/png — просто переименуй в
   `icon.png`, либо измени путь в `scripts/build_zastogram_ci.sh`).
2. Запусти сборку (push в ветку). Готово — иконка приложения во всей системе
   станет твоей картинкой с полупрозрачным самолётиком Telegram поверх неё.

Сейчас здесь лежит сгенерированная дефолтная иконка (кот). Замени файл на свою —
и при следующей сборке она применится автоматически.

## Что делает генератор

- **Legacy-иконки** (`ic_launcher.png`, `ic_launcher_round.png`, 5 плотностей):
  твоя картинка, вписанная в квадрат, + полупрозрачный самолётик Telegram.
- **Adaptive-иконка (Android 8+)**: фон — твоя картинка, передний план —
  полупрозрачный самолётик. Лаунчер сам скруглит/обрежет по маске системы.
- Прозрачность самолётика настраивается переменной окружения `PLANE_ALPHA`
  (по умолчанию `0.55`). Если хочешь без самолётика — поставь `PLANE_ALPHA=0`.

## Без своей картинки

Если `branding/icon.png` отсутствует — скрипт ничего не делает и сборка
использует иконку upstream (сборка никогда не ломается).
